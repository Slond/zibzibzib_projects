# Поиск работы — интерактивный прототип

Откройте `index.html` в браузере. Весь интерфейс, стили и логика находятся в одном файле; подключение к интернету не требуется. Для наиболее предсказуемого хранения файлов можно открыть через локальный сервер:

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory prototypes/jobs
```

Адрес: http://127.0.0.1:8767

## Что попробовать

1. На обзоре открыть компанию из списка следующих действий, отложить задачу или отметить её выполненной. После завершения доступна быстрая кнопка «Отменить» (12 секунд). У завершённого события остаётся кнопка «Вернуть» в расписании и карточке вакансии; выполненное действие можно вернуть из истории карточки, пока не назначено новое. Отмена сохраняется после перезагрузки и убирает ошибочную запись о завершении.
2. Добавить отклик. По умолчанию напоминание назначается на семь дней после отклика.
3. В карточке поменять этап, добавить заметку, указать следующее действие и его дату.
4. Нажать «Контакт сегодня»: дата общения обновится, для незавершённого отклика появится напоминание через неделю.
5. Добавить собеседование через календарь или карточку вакансии. Оно появится в обоих местах.
6. Посмотреть список и доску, поиск по компании, позиции, источнику или контакту, фильтры.
7. Загрузить несколько документов, скачать их, выбрать основное CV. Версия CV в прошлых откликах сохраняется.
8. Открыть воронку, переключить период, сравнить достигнутые этапы с текущим состоянием.
9. Перезагрузить страницу: записи и загруженные файлы сохраняются в этом браузере.
10. Экспортировать записи в JSON или восстановить исходные данные кнопкой «Сбросить демо».

## Ограничения демо

- Фиксированная дата: **16 октября 2026**, часовой пояс встреч — Алматы, UTC+5. «Сегодня» и «через неделю» считаются от этой даты.
- 18 вымышленных вакансий, демонстрационные контакты и три встроенных образца документов. PDF скачиваются как PDF, сопроводительное письмо TXT - как TXT, загруженные пользователем документы сохраняют исходные имя, формат и содержимое. Настоящего CV в проекте нет.
- Записи сохраняются в localStorage, загруженные документы — в IndexedDB. Они доступны только в этом браузере и для этого адреса. Очистка данных сайта удалит их. Экспорт JSON содержит метаданные, но не содержимое документов.
- Общие ссылки на CV и фоновые уведомления представлены как будущие возможности. Отправки сообщений, автоматических откликов и интеграций с почтой нет.
- Доска открывает карточки; изменение этапа выполняется в карточке. Перетаскивание между колонками не реализовано.
- Прототип не подключён к основной базе, авторизации и меню рабочего сайта. Для него не нужны изменения основного приложения.
- Существующий `styles.css` не используется и сохранён без изменений.

## Предлагаемая структура рабочего раздела

**Обзор:** следующие действия и просрочки, план недели, ближайшие интервью, закреплённое CV, необязательная цель по числу отправленных за неделю откликов. Цель не оценивает качество вакансий и учитывает дату отклика, независимо от его текущего статуса.

**Отклики:** сохранённые вакансии, компания, роль, объявление, зарплата с валютой/периодом/gross-net, формат и допустимая география найма, источник, приоритет, контакты, дата отклика, дата последнего общения, отправленная версия CV, текущий этап, история, заметки и причина завершения.

**Календарь:** собеседования и подготовка, напоминания, сроки тестовых заданий и ответа на оффер. Событие связано с вакансией, хранит часовой пояс, длительность и ссылку на встречу.

**Документы:** несколько CV, сопроводительные, портфолио; основной файл; стабильные ссылки, отзыв доступа и скачивание. Привязка отправленной версии к отклику должна быть неизменяемой: загрузка обновлённого CV создаёт новую версию. Для анкет с загрузкой нужен файл, а не только ссылка.

**Воронка:** текущие состояния отдельно от достигнутых этапов; анализ группы откликов по дате подачи, конверсии, источники, причины отказов и время ожидания. При закрытии отклика его история сохраняется. Пропущенные этапы в реальной системе лучше хранить явно, не смешивая их с состоявшимися интервью.

### Что заложить сразу

- Каждая вакансия имеет следующее действие и срок либо явно завершена. Фиксация контакта и выполнение задачи — разные действия.
- Напоминание по умолчанию — семь дней от последнего контакта; доступны собственная дата, перенос и завершение.
- Отказы и снятые отклики не создают новые напоминания; запланированные встречи при закрытии требуют явного решения об отмене.
- Версии документов, история этапов, мягкое удаление/архив и резервное копирование.
- Индивидуальный доступ к записям через существующую авторизацию. Файлы по умолчанию закрыты; доступ по ссылке включается отдельно и может быть отозван.
- Проверка дубликатов по компании, роли и ссылке до добавления; предупреждение о пересекающихся собеседованиях.

### После проверки прототипа

Первая рабочая версия: записи + календарь + документы + история + воронка; один канал доставки напоминаний на выбор. Далее — импорт/экспорт календаря, шаблон сообщения рекрутеру, сравнение офферов, поиск и импорт вакансий. Автоматическую отправку откликов и сложную оценку соответствия CV лучше рассматривать отдельно после проверки основного сценария.

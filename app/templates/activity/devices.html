iOS не сообщает командам и приложениям, какая программа сейчас на экране. С телефона уходит только геолокация.

{{ base_url }}/activity/api/location/{{ device.token }}
  1. Откройте Shortcuts и создайте команду.
  2. Добавьте действие «Текущее местоположение».
  3. Добавьте «Получить содержимое URL»: метод POST, адрес выше.
  4. Заголовок Content-Type: application/json
  5. Тело запроса — JSON. В поля latitude и longitude вставьте широту и долготу из предыдущего действия.
  6. Автоматизация → Время суток → каждый час → запуск этой команды.
{"latitude": 0, "longitude": 0}
{% else %}

Одна команда скачивает клиент в свою папку и включает его при входе в систему. До входа окон ещё нет, поэтому старт привязан к рабочему столу, а не к включению питания. После смены токена вставьте команду ещё раз. Если адрес начинается с localhost, подставьте внешний домен.

{% if device.platform == 'windows' %} 
set DIR=%APPDATA%\activity-client
mkdir "%DIR%"
curl.exe -fsSL "{{ base_url }}/activity/api/client/{{ device.token }}" -o "%DIR%\client.py"
curl.exe -fsSL "{{ base_url }}/activity/api/client/{{ device.token }}/requirements.txt" -o "%DIR%\requirements.txt"
py -3 -m venv "%DIR%\venv"
"%DIR%\venv\Scripts\python.exe" -m pip install -r "%DIR%\requirements.txt"
(
echo @echo off
echo "%DIR%\venv\Scripts\python.exe" "%DIR%\client.py" --server {{ base_url }} --token {{ device.token }}
) > "%DIR%\start.cmd"
schtasks /Create /F /SC ONLOGON /TN ActivityClient /TR "\"%DIR%\start.cmd\""
"%DIR%\start.cmd"

Вставьте это в cmd. Клиент стартует при следующем входе и сразу после этих команд.

{% else %} 
set -euo pipefail
DIR="$HOME/Library/Application Support/activity-client"
PLIST="$HOME/Library/LaunchAgents/activity-client.plist"
mkdir -p "$DIR" "$HOME/Library/LaunchAgents" "$HOME/Library/Logs"
curl -fsSL "{{ base_url }}/activity/api/client/{{ device.token }}" -o "$DIR/client.py"
curl -fsSL "{{ base_url }}/activity/api/client/{{ device.token }}/requirements.txt" -o "$DIR/requirements.txt"
python3 -m venv "$DIR/venv"
"$DIR/venv/bin/python" -m pip install -r "$DIR/requirements.txt"
PY="$DIR/venv/bin/python"
python3 - "$PLIST" "$PY" "$DIR/client.py" "$DIR" "{{ base_url }}" "{{ device.token }}" << 'PY'
import pathlib, plistlib, sys
plist, py, script, directory, server, token = sys.argv[1:]
log = str(pathlib.Path.home() / "Library/Logs/activity-client.log")
data = {
    "Label": "activity-client",
    "ProgramArguments": [py, script, "--server", server, "--token", token],
    "WorkingDirectory": directory,
    "RunAtLoad": True,
    "KeepAlive": True,
    "StandardOutPath": log,
    "StandardErrorPath": log,
}
pathlib.Path(plist).write_bytes(plistlib.dumps(data))
PY
plutil -lint "$PLIST"
DOMAIN="gui/$(id -u)"
launchctl bootout "$DOMAIN/activity-client" 2>/dev/null || true
launchctl enable "$DOMAIN/activity-client"
launchctl bootstrap "$DOMAIN" "$PLIST"

Вставьте это в Терминал. Пакеты ставятся в отдельное окружение рядом с клиентом, системный Python не меняется. macOS один раз спросит «Универсальный доступ» для Python: без этого не прочитается название окна. Запись экрана не нужна.

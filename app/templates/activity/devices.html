iOS не сообщает командам и приложениям, какая программа сейчас на экране. С телефона уходит только геолокация. Через 45 минут без новой точки местоположение считается неизвестным. В Shortcuts нет готового расписания «каждые 15 минут»; для непрерывной дорожки нужны отдельные частые запуски.

{{ base_url }}/activity/api/location/{{ device.token }}
  1. Откройте Shortcuts и создайте команду.
  2. Добавьте действие «Текущее местоположение».
  3. Добавьте «Получить содержимое URL»: метод POST, адрес выше.
  4. Заголовок Content-Type: application/json
  5. Тело запроса — JSON. В поля latitude и longitude вставьте широту и долготу; в accuracy — точность в метрах, в captured_at — текущую дату в ISO 8601. Если точность недоступна, поле accuracy можно убрать.
  6. Автоматизация → Время суток → выберите время → ежедневно → запускать немедленно. Для нескольких запусков добавьте отдельные автоматизации (например, 08:00, 08:15, 08:30). Можно добавить запуск при прибытии и уходе.
{"latitude": 0, "longitude": 0, "accuracy": 10, "captured_at": "2026-10-09T12:00:00+05:00"}

Одна команда скачивает клиент в свою папку и включает его при входе в систему. До входа окон ещё нет, поэтому старт привязан к рабочему столу, а не к включению питания. После смены токена вставьте команду ещё раз. Если адрес начинается с localhost, подставьте внешний домен.

{% if device.platform == 'windows' %} 
set DIR=%APPDATA%\activity-client
mkdir "%DIR%" 2>nul
schtasks /End /TN ActivityClient 2>nul
powershell -NoProfile -Command "Get-CimInstance Win32_Process | Where-Object { $_.Name -match '^python(w)?\.exe$' -and $_.CommandLine -like ('*' + $env:APPDATA + '\activity-client\client.py*') } | ForEach-Object { Stop-Process -Id $_.ProcessId -ErrorAction SilentlyContinue }"
curl.exe -fsSL "{{ base_url }}/activity/client.py" -o "%DIR%\client.py.new"
if errorlevel 1 exit /b 1
move /Y "%DIR%\client.py.new" "%DIR%\client.py" >nul
curl.exe -fsSL "{{ base_url }}/activity/requirements.txt" -o "%DIR%\requirements.txt"
set "PY="
py -3 -c "import sys" >nul 2>&1
if not errorlevel 1 set "PY=py -3"
if not defined PY python -c "import sys" >nul 2>&1
if not defined PY if not errorlevel 1 set "PY=python"
if not defined PY echo Python 3 не найден. Скачайте его с https://www.python.org/downloads/windows/ и включите Add python.exe to PATH. Закройте cmd и вставьте команду снова.
if defined PY %PY% -m venv "%DIR%\venv"
if exist "%DIR%\venv\Scripts\python.exe" "%DIR%\venv\Scripts\python.exe" -m pip install -r "%DIR%\requirements.txt"
if exist "%DIR%\venv\Scripts\python.exe" (
> "%DIR%\start.cmd" echo @echo off
"%DIR%\venv\Scripts\python.exe" "%DIR%\client.py" --server {{ base_url }} --token {{ device.token }} --configure-only
>> "%DIR%\start.cmd" echo "%DIR%\venv\Scripts\python.exe" "%DIR%\client.py"
schtasks /Delete /F /TN ActivityClient 2>nul
powershell -NoProfile -Command "$s=(New-Object -ComObject WScript.Shell).CreateShortcut([IO.Path]::Combine([Environment]::GetFolderPath('Startup'),'ActivityClient.lnk')); $s.TargetPath=$env:APPDATA+'\activity-client\start.cmd'; $s.WindowStyle=7; $s.Save()"
call "%DIR%\start.cmd"
)

Вставьте это в cmd целиком. Если Python ещё не стоит, команда остановится и напишет, откуда его скачать. Клиент стартует при следующем входе и сразу после этих команд.

import pathlib, plistlib, sys
plist, py, script, directory = sys.argv[1:]
log = str(pathlib.Path.home() / "Library/Logs/activity-client.log")
data = {
    "Label": "activity-client",
    "ProgramArguments": [py, script],
    "WorkingDirectory": directory,
    "RunAtLoad": True,
    "KeepAlive": True,
    "StandardOutPath": log,
    "StandardErrorPath": log,
}
pathlib.Path(plist).write_bytes(plistlib.dumps(data))
PY
plutil -lint "$PLIST"
DOMAIN="gui/$(id -u)"
launchctl bootout "$DOMAIN/activity-client" 2>/dev/null || true
launchctl enable "$DOMAIN/activity-client"
launchctl bootstrap "$DOMAIN" "$PLIST"

Вставьте это в Терминал. Пакеты ставятся в отдельное окружение рядом с клиентом, системный Python не меняется. macOS один раз спросит «Универсальный доступ» для Python: без этого не прочитается название окна. Запись экрана не нужна. Проверка без отправки: "$HOME/Library/Application Support/activity-client/venv/bin/python" "$HOME/Library/Application Support/activity-client/client.py" --preview

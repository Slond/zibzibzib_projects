# Сбор ссылок Muscle & Strength

Скрипт `scripts/collect_muscle_strength.py` собирает разделы, опубликованные на https://www.muscleandstrength.com/exercises, и все доступные через пагинацию страницы каждого раздела. Он извлекает карточки упражнений, а не ссылки из навигации или комментариев, и объединяет повторы одного URL между разделами.

Запуск из корня проекта в Python-окружении с зависимостями из `requirements.txt`:

```sh
python scripts/collect_muscle_strength.py
```

По умолчанию результаты находятся в `data/exercise_catalog/muscle_strength/` (игнорируются Git):

- `exercise_urls.txt` — уникальные ссылки, по одной на строку.
- `exercises.csv` — английское и русское названия, ссылка, мышцы, инвентарь, тип движения, опыт, разделы и ссылка на превью. UTF-8 с BOM для Excel; потенциальные формулы экранируются.
- `exercises.json` — те же данные со стабильными ID, списками характеристик и сведениями о полноте сбора.
- `categories.json` — разделы, тип раздела, число обработанных страниц и упражнений.
- `summary.json` — дата, количество ссылок, ошибки, оставшиеся страницы и флаг `complete`.
- `checkpoint.json` — промежуточные результаты для продолжения.

Каждая успешно разобранная страница сохраняется атомарно. Повтор того же запуска продолжает обход и не загружает уже сохранённые страницы. Новые разделы/изменения сайта появляются при полном обновлении:

```sh
python scripts/collect_muscle_strength.py --refresh
```

Для пробного запуска или сбора порциями:

```sh
python scripts/collect_muscle_strength.py --max-pages 2
python scripts/collect_muscle_strength.py --output data/exercise_catalog/another-run --delay 2
```

`--max-pages` ограничивает число новых страниц разделов, без учёта главной и robots.txt. Завершённый обход возвращает код 0, незавершённый — 2. `complete: true` означает, что все разделы главной страницы и вся найденная пагинация пройдены; это не обещание соответствия рекламному числу упражнений или наличия записей, на которые каталог не ссылается. Ошибки и остановка не выдаются за полный результат.

Скрипт работает последовательно, с интервалом не меньше 1 секунды (по умолчанию 1,5), учитывает robots.txt и прекращает обход при 403/429 или странице проверки браузера. CAPTCHA, прокси для обхода ограничений и закрытые AJAX-методы не используются. После восстановления доступа можно продолжить тот же запуск. Перенаправления ограничены доменом и каталогом упражнений; размер ответов ограничен. Параллельные запуски в один каталог не поддерживаются.

## Перевод и последующий импорт

Сейчас собираются ссылки, названия и метаданные карточек; страницы отдельных упражнений, полные инструкции, видеофайлы и изображения не скачиваются. `preview_url` — внешняя ссылка. Данные сохраняют исходные названия и URL Muscle & Strength.

Для перевода имён создайте рядом с результатами отдельный `translations.ru.json` (ключ — URL или стабильный ID, значение — перевод):

```json
{
  "https://www.muscleandstrength.com/exercises/front-squat.html": "Фронтальный присед"
}
```

Следующий запуск подставит переводы в `name_ru` в JSON и CSV. Можно указать другой файл через `--translations`. Не редактируйте сгенерированные CSV/JSON как единственное место хранения перевода: они пересоздаются, а отдельный файл переводов сохраняется и при `--refresh`.

Сборщик не подключается к базе приложения и не создаёт упражнения в аккаунте. Для общей базы сайта следующим отдельным шагом потребуются проверка переводов, сопоставление вариантов упражнений и импорт. Описание техники и ссылки на видео можно затем извлекать из отдельных страниц существующим парсером `app/services/sport_lookup.py`, когда источник разрешает загрузку.

Проверки: `python -m pytest tests/test_exercise_collector.py -q`.

## Опубликованный перевод

Все 1133 названия переведены и включены в `app/catalogs/sport_exercises.json`. Русские названия учитывают хват, стойку, одностороннее выполнение и оборудование. Английские названия и исходные URL сохранены для сопоставления. Сборка из полной выгрузки и отдельного проверенного файла переводов:

```sh
python scripts/build_sport_catalog.py
```

Сборка проверяет наличие перевода для каждого упражнения, полноту исходного сбора и уникальность ссылок. Прежние девять ID сопоставляются по URL. Публикуется подготовленный файл в `app/catalogs/`, а не локальный checkpoint/выгрузки. Для следующего обновления переводы также можно восстановить из полей `sourceUrl` и `name` опубликованного JSON.
